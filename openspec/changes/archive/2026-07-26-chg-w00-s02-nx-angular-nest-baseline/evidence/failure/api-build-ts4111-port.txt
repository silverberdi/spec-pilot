# API build failure — TS4111 process.env.PORT

Observed during operator validation (serve/build) on 2026-07-25.

Error:
  apps/api/src/main.ts — TS4111
  Property 'PORT' comes from an index signature, so it must be accessed with ['PORT'].

Cause:
  TypeScript strict / noPropertyAccessFromIndexSignature rejects process.env.PORT.

Remediation (applied):
  Replace process.env.PORT with process.env['PORT'].
  Preserve default port 3000.
  Do not weaken TypeScript strictness.
  Do not change the GET /health contract.
