# Remote Actions corroboration note

GitHub Actions workflow run logs (after an authorized push to `main`) may corroborate post-push remote verification.

They do **not** replace the required local full quality-gate `PASS` evidence under `evidence/success/quality-gates-pass.txt`.

They must **not** be described as a pre-entry block onto `main`.

Temporary absence of a remote result does not invalidate completed local closure evidence.
