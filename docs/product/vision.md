# Product Vision

SpecPilot becomes the supervised control plane for specification-driven delivery across multiple local repositories. OpenSpec remains authoritative; executors implement; SpecPilot validates; the human owner authorizes critical transitions.

## North-star outcome

For every reviewed change, SpecPilot should answer:

1. Is this the correct next change?
2. Is planning complete enough that the executor only needs `/opsx:apply <change>`?
3. Does the applied implementation satisfy the approved artifacts?
4. Is the change truly ready for Verify or Sync?
5. What exact prompt must be sent when it is not ready?

## Long-term evolution

1. Supervised DeepSeek validation console.
2. Google authentication.
3. Supervised command execution.
4. Cursor/Codex orchestration.
5. OpenCode multi-model runtime.
6. Controlled automation with human gates.
