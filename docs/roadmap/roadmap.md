# SpecPilot Roadmap

| Wave | Name | Goal |
|---|---|---|
| w00 | Project Foundation | Governed repository, OpenSpec, architecture, Nx baseline, local infrastructure |
| w01 | Project Registry and Discovery | Register projects and inspect Git/OpenSpec/configuration |
| w02 | Secure Context Assembly | Minimal context bundles, exclusions, secret protection, manifests |
| w03 | DeepSeek Review Engine | Provider integration, schemas, budgets, runs and cost tracking |
| w04 | New Change Guidance | Determine next work and create executor-ready prompts |
| w05 | Planning Quality Gate | Review proposal/design/specs/tasks to `APPLY_READY` |
| w06 | Applied Change Review | Review implementation to `READY_FOR_VERIFY` |
| w07 | Verify and Sync Readiness | Validate exact PASS and closure gates to `READY_FOR_SYNC` |
| w08 | Operational Console Completion | Full multi-project operational UX, history and metrics |
| w09 | Google Authentication | Google sign-in, user ownership and secure migration |
| w10 | Supervised Execution | Optional future command runner and human gates |
| w11 | Optional Executor Runtime | Future supervised adapters and controlled orchestration; no current development-role implication |
